# lukasavicus.github.io

Personal site of Lucas Lukasavicus, served by GitHub Pages (Jekyll) at https://lukasavicus.github.io.

## Three versions

| Path | What |
|---|---|
| `/` | **Version A**: the current site, design inspired by callieschweitzer.com. Static HTML generated by `_build/build.js`. |
| `/b/` | **Version B**: same content, design inspired by surinder.design. Static HTML (Astro bundle in `b/_astro/`). |
| `/2016/` | The original 2016 site, preserved as it was, plus a banner pointing back to the current one. |

A and B share `/assets/` (photos, logos). Both are live so the two designs can be compared by path.

## Articles and research

- `/articles/`: posts in `_posts/`, rendered by Jekyll with `_layouts/post.html` (permalink `/articles/:title/`).
- `/research/`: the documents behind the 2026 redesign (reference survey, page superset, decisions, Surinder section map), rendered with `_layouts/default.html`.
- `/llms.txt`: machine-readable version of the site content.

## Running locally

Full site (articles and research need Jekyll):

```sh
bundle exec jekyll serve
# or, without Ruby:
docker run --rm -p 4000:4000 -v "$PWD:/srv/jekyll" -w /srv/jekyll jekyll/jekyll:4 jekyll serve --host 0.0.0.0
```

Static parts only (A, B, 2016):

```sh
python3 -m http.server 8080
```

Regenerate version A after editing `_build/build.js` or `_build/spot-body.html`:

```sh
cd _build && node build.js
```

This also regenerates `_layouts/default.html`, so the Jekyll pages keep the same shell as version A.
